# FocusReader GitHub Pages

This repository hosts the privacy policy for FocusReader iOS app.

## Setup Instructions

1. **Create GitHub Repository**
   - Go to https://github.com/new
   - Repository name: `focusreader`
   - Description: "Privacy policy for FocusReader iOS app"
   - Public repository
   - Click "Create repository"

2. **Upload Files**
   - Upload `index.html` to the root of the repository
   - Commit changes

3. **Enable GitHub Pages**
   - Go to repository Settings
   - Scroll to "Pages" section (left sidebar)
   - Under "Source", select "Deploy from a branch"
   - Branch: `main` (or `master`)
   - Folder: `/ (root)`
   - Click "Save"

4. **Get Your URL**
   - Wait 2-3 minutes for deployment
   - Your privacy policy will be at:
   - `https://[your-username].github.io/focusreader/`

5. **Use in App Store Connect**
   - Copy the URL above
   - Paste it in the "Privacy Policy URL" field
   - Also use it in the app's Info.plist if needed

## Files in This Folder

- `index.html` - Privacy policy webpage (upload this to GitHub)
- `README.md` - These instructions
